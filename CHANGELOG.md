# Changelog

## 0.1.0-alpha.1 - non-cryptographic subset, M11 audit in progress

- Implements qpdf 12.4.2 non-cryptographic structural operations in managed C#: strict reading with bounded recovery, page selection and merge, writer controls, content transforms, overlays, appearances, JPEG processing, QDF, and linearization, through typed, argv, and job JSON routes.
- 152 of 157 option/context entries are labeled complete; 5 stay partial: remaining job-file grammar/default/context auditing, checker combinations, parser ownership/nested recovery, and the accepted no-Zopfli and four-component CMYK profiles. M11 containment and validation gates remain open. Crypto operations are excluded and fail explicitly.
- Compose argv settings with repeated and nested job files through the shared loader/parser. Return JSON inspection without a file through `QpdfExecutionResult.OutputText`; close whole-file preliminary input leases before replacement/publication.
- Run checking and ordered count/linearization/xref/object/page/image/attachment listings on one document with original identities. Preserve native object-selector prefixes and generation setter semantics; release unowned input admission on failed reads before engine construction. Checker binary/selection/transformation combinations remain open.
- Release exclusive document input, xref and page-view storage on disposal and failed opening, including host-close faults. Preserve returned immutable values, caller-funded component borrowing and page counts; govern page-list/traversal capacities.
- Track accepted values against independently escaping wrappers and backing storage, including numeric text, dictionary key views and stream buffers. Govern weak-ledger capacities and growth; preserve prior aliases on failed acceptance. Scope the internal JSON reader through serialization and close it before output creation, preserving main/sidecar targets on input-close faults and retaining JSON failure/cancellation counters. Diagnostic admission/retirement and cold/native-state containment remain under audit.
- Rewrite bare argv input/output pairs through the shared whole-file job plan, with an optional output separator. Apply linearization and object-stream writer controls without requiring page selection; reject missing/extra arguments before input access.
- See docs/SUPPORTED-PROFILE.md, docs/COMPATIBILITY.md, and docs/PROGRESS.md for the exact profile, per-option evidence, and audit status.
